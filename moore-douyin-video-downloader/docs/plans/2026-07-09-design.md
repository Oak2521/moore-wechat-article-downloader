# 设计方案：moore-douyin-video-downloader

日期：2026-07-09

用自然语言驱动的抖音视频批量下载 Skill。核心目标：**高清、无水印**地批量下载
「指定账号的作品」「我的喜欢列表」「我的收藏列表」，输出干净可用的本地文件。

## 1. 设计原则（沿用微信版）

- **纯 Python 标准库**，无需 `pip install`（仅代理捕获模式需要 `mitmproxy`）。
- **说话即操作**：AI 负责把用户意图翻译成 CLI，处理代理开关、列表选择等交互。
- **被动捕获优先**：不主动伪造抖音的反爬签名，而是拦截用户自己客户端产生的
  接口返回，稳定且合规。
- **输出干净可用**：视频 + 封面 + 元数据 + `index.csv`，按账号归档。
- **范围克制**：只下载公开可见 / 用户自己有权访问的内容；不做转发、二创、SaaS。

## 2. 为什么以「代理捕获」为主路径

抖音 Web/App 接口带一整套运行时签名（`a_bogus` / `X-Bogus` / `msToken` /
`ttwid` / 设备指纹），由混淆 JS 动态生成且频繁更换。主动直连需要在 JS 引擎里
跑签名脚本或依赖第三方签名库，**维护成本高、随时失效**。

被动捕获反过来：**用户在自己的抖音客户端里正常浏览目标列表并向下滚动，工具通过
本地代理读取客户端已经算好签名后拿到的接口返回**。这与微信版「滚动历史列表→
捕获 getmsg」是同一模型，绕开签名，稳定且姿态清白。

三种目标列表天然统一到同一套捕获逻辑，区别只是**用户在客户端打开哪个页面**：

| 目标 | 用户在客户端打开 | 触发的接口（响应含 `aweme_list`） |
|------|----------------|-------------------------------|
| 指定账号作品 | 该账号主页「作品」 | `.../aweme/v1/web/aweme/post/` |
| 我的喜欢 | 「我」→「喜欢」 | `.../aweme/v1/web/aweme/favorite/` |
| 我的收藏 | 「我」→「收藏」 | `.../aweme/v1/web/aweme/listcollection/` 及 `.../aweme/v1/web/aweme/collection/` |
| 合集 | 合集页 | `.../aweme/v1/web/mix/aweme/` |
| 单条详情 | 单个视频页 | `.../aweme/v1/web/aweme/detail/` |

addon 按 URL 前缀匹配上述任意接口，解析响应里的作品并按来源打 `source` 标签。
喜欢/收藏必须是**用户登录自己的账号**后浏览自己的列表——本工具只读用户自己的
流量，不代替用户登录、不触碰他人私密数据。

## 3. 高清 / 无水印策略

抖音单条作品的视频对象里通常有多路地址：

- `video.play_addr.url_list`：播放地址（一般**无可见水印**）。
- `video.bit_rate[]`：多档码率，每档有 `play_addr.url_list` 与 `bit_rate` 数值。
- `video.download_addr` / 带 `watermark` 的分享地址：**有水印**，不用。

选择逻辑 `best_video_url(video, quality)`：

1. `quality=best`（默认）：在 `bit_rate[]` 里按 `bit_rate` 数值降序取第一档的
   `play_addr.url_list[0]`；无 `bit_rate` 时回退 `video.play_addr.url_list[0]`。
2. `quality=source`：直接取 `video.play_addr.url_list[0]`。
3. 一律避开 `download_addr` / `playwm`（水印源）。

图文作品（`images[]`）：逐张取 `images[i].url_list[0]`（优先无水印的原图字段）。

职责划分：
- `douyin_downloader.py`：所有纯逻辑（解析 aweme、选最佳地址、命名、写
  `index.csv`）、下载管道、会话与选择、跨平台系统代理开关与进程管理。
- `douyin_capture_addon.py`：只做「匹配目标接口 URL → 解析响应 → 追加去重到
  会话捕获文件 → 写安全就绪标记」，绝不落盘任何 cookie/token/签名。

## 5. CLI 契约

```bash
# 代理捕获模式（主路径）
douyin_downloader.py capture-setup [--install] [--yes]          # 检查/安装 mitmproxy + 证书指引
douyin_downloader.py capture-prepare "<账号名或说明>" --port 8899 # 启动代理 + 确认后开启系统代理，返回 session-id
douyin_downloader.py capture-status <session-id>
douyin_downloader.py capture-finish <session-id> [--yes]        # 停代理 + 还原系统代理

# 列表与选择
douyin_downloader.py preview --session-id <id> [--limit N]
douyin_downloader.py select --session-id <id> (--latest N | --indices "1,3,5" | --range "1-20" | --contains "关键词")
douyin_downloader.py download-selected --session-id <id> [--output-dir DIR] [--quality best|source] [--cookie-file F]

# 直接下载（备选，尽力而为）
douyin_downloader.py download-json "<导出的 aweme JSON 文件>" [--output-dir DIR] [--quality best|source]
douyin_downloader.py download-url "<分享链接或视频ID>" [--output-dir DIR]

# 工具
douyin_downloader.py list [--output-dir DIR]
validate_outputs.py "<dir>"
```

wizard 风格 gate（AI 处理，不立即降级）：

| Gate | 处理 |
|------|------|
| `need_mitmproxy` | 提示安装 → `capture-setup --install --yes` |
| `need_proxy_confirm` | 向用户确认开启系统代理 → 确认后继续 |
| `need_cert_trust` | 引导安装并信任 mitmproxy 根证书 |
| `need_scroll` | 让用户在客户端滚动目标列表，滚够后继续 |
| `need_selection` | 聊天中列出作品（描述+日期），让用户选 |

## 6. 输出结构

默认目录：`~/Downloads/douyin-videos/<账号名或session>/`

```text
index.csv                              所有作品元数据索引
videos/<seq>-<aweme_id>-<safe_desc>.mp4  视频
covers/<seq>.jpg                       封面
images/<seq>/<n>.jpg                   图文作品的图片
meta/<seq>.json                        单条完整元数据（脱敏）
```

内部会话数据：`~/.moore/douyin-video-downloader/`
```text
sessions/<session-id>.json             会话状态
captures/<session-id>.jsonl            捕获的作品（去重）
proxy/<session-id>.state.json          代理进程状态
system_proxy_state.json                系统代理备份（用于还原）
```

## 7. 选择契约（沿用微信版）

- `--latest N`：当前列表前 N 条
- `--indices "1,3,5"`：指定序号
- `--range "1-20"`：连续区间
- `--contains "关键词"`：描述包含关键词
过滤顺序：`--contains` → `--indices`/`--range` → `--latest`。

## 8. 合规边界（硬性）

可以：下载公开账号的公开作品；下载**用户自己登录后**可见的喜欢/收藏；本地存档。

不要：绕过私密账号 / 登录墙 / 付费内容；代替用户登录或窃取凭证；打印或落盘
cookie/token/msToken/签名；抓取他人私密数据；把下载内容用于二次分发或商用；
把工具扩展成云服务 / 批量代抓服务。

安全实现：addon 只写作品字段与安全就绪标记；系统代理开关需 `--yes` 显式确认并
在结束时还原；捕获与元数据统一经过脱敏（剔除 URL 上的签名/票据参数）。

## 9. 测试策略

无法在无抖音客户端、强反爬的环境里做真实端到端，因此：
- 纯逻辑（解析多种 JSON 形态、最佳地址选择、图文、去重、命名、`index.csv`、
  选择过滤、接口 URL 匹配、脱敏）用 fixtures 做**离线契约测试**，必须全绿。
- 网络下载与代理/进程控制封装为独立函数，逻辑部分离线可测；真实抓取需在用户
  自己机器上验证（文档明确说明）。

## 10. 里程碑

1. 解析层 + 最佳地址 + 脱敏（离线可测）
2. 下载管道（视频/封面/图集/meta/index.csv）
3. 会话 + 选择 + 预览
4. 代理控制 + 捕获 addon（跨平台，端口 8899）
5. SKILL.md / references / README / 合规
6. 契约测试全绿 → 安装为本地 skill
